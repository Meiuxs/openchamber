OpenChamber 2.7.0（2026-11-08）

新功能
  - 扩展：用 /new-extension 描述需求，智能体写出并构建扩展，聊天里直接出现安装按钮。
    扩展可在聊天里绘制界面、回答智能体提问、主动操作会话、添加动作与 @ 行，并可提供更新
  - 文件：Word、PowerPoint、Excel、OpenDocument 在应用内打开。表格可排序、筛选、调整列宽、
    带公式和撤销编辑；选中的单元格或文字作为引用送入输入框，智能体改过的单元格保留标记
  - 聊天：回复里的 shell 代码块可直接运行，输出显示在代码块中，命令结束后智能体继续
  - 文件：SQLite、Parquet、zip、Jupyter 只读预览；Office 文件可在改动视图对比；
    Markdown 导出 Word 和 PDF，CSV 导出 Excel
  - 上下文面板：Session Totals 显示整段会话的输入、输出、推理、缓存读写与命中率，
    工作状态显示上一轮的缓存命中
  - Git：用 gt CLI 登录的 Gitea 实例出现在设置 > 集成，可用 gt CLI 免 token 登录
  - 快捷键：设置里列出全部键盘命令，可重新绑定和搜索，命令面板动作也能设快捷键，绑定可清空
  - 插件：每张插件卡上的开关可停用插件并保留它的配置项和选项
  - 主题与外观：新增 Patina 亮/暗主题，聊天字号可单独调整
  - 会话：后台生成图片时会话显示为工作中；粘贴 session id 自动转成会话链接；
    Shift+Enter 延续有序列表；统计面板新增 Today 范围；定时任务可指定自己的 worktree
  - 聊天表单：分页表单每页有下一步、末页有发送；等待回答的页面可拒绝，
    智能体会收到拒绝而不会替你选择

改进
  - 移动端整体重做：统一顶栏、弹窗与底部抽屉，连接页与实例合并，
    Git 面板、设置和编辑器查找栏按手机屏幕重做
  - 大表格和数据库打开不再卡住界面，例如 10 万行工作簿或百万行 SQLite 文件
  - 智能体工具显示做了什么，展开可看结果和截图；拉取请求更新以本地语言的一行文字呈现
  - 侧边栏所有列表显示目录结构，每行都能移动到文件夹
  - /btw 可选智能体，并用常用快捷键切换模型和思考深度
  - 超过 10 MB 的文件以路径备注形式附加，由智能体按需读取
  - Goals 与就绪通知会等待子智能体和后台生成的图片

修复（节选）
  - 上下文面板：长会话开着 Raw Messages 流式输出时不再卡死
  - Git：大工作区不再因后台扫描变慢，含数百个 worktree 的仓库启动不再冻结；
    中文、日文、韩文路径的项目能列出会话；Azure DevOps 远端给出明确的地址提示
  - Worktrees：含 Git LFS 的 SSH 远端可再创建；合并后归档恢复正常；
    智能体创建的 worktree 会执行项目的 setup 命令
  - 聊天：表单始终有发送按钮；一个渲染失败的块不再隐藏周围的图表和表格；
    后台消息到达或打开 Activity 时，等待回答的提问和表单保留
  - 设置/技能：停用的技能显示为关闭，开关保留 opencode.jsonc 里的注释
  - CLI 与终端：更新后 macOS、Windows 的自启服务会重启，Docker 里会话命令可用；
    输入法文字显示在光标处，旧版 Bun 下终端可用

说明
  - 内置 OpenCode 更新到 2.2.6。以上为上游 2.7.0 内容，完整条目见 changelog/2.7.0.md
  - 本包同时包含内网定制能力：本地议题系统、企业模式与用户目录 policy.json、
    内网 Git HTTP 白名单、模型元数据内网地址、企业技能目录与隐藏内置技能库、
    内网 npm 镜像、Git 2.20.x 低版本兼容、GitLab 老实例探测，
    以及带中文注释的 policy.example.json 样例
  - 本包安装脚本（install.ps1 / install.sh）全程无需管理员/root：策略文件与环境变量都写在
    当前用户目录；npm 全局前缀若指向不可写的系统目录，脚本只复用已有的用户级 npm 目录，
    不改写 .npmrc 等 npm 配置
  - 安装、配置与启动命令见 INSTALL.txt。更新后需重启 OpenChamber 服务，旧进程仍运行旧代码
