### 复核中确认的关键事实（后续可复用）
- 运行时是 **Bun** 不是 Node 24：Dockerfile runtime = oven/bun:1.4.4，入口执行 `bun packages/web/bin/cli.js`；`bin/cli.js` 只在没有 bun 时降级到 node。
- **`system-ca.js` 在 Bun 下是 no-op**（`tls.getCACertificates` 不存在），自签 CA 必须靠 `NODE_EXTRA_CA_CERTS`，否则「git 通、UI 拉不到数据」。
- `models.dev` 硬编码 **4 处** + 客户端公网回退：`server/index.js:211`、`opencode/models-metadata.js:1`、`ui/stores/useConfigStore.ts:38,826`、`vscode/src/bridge-fs-helpers-runtime.ts:531`；另有 provider logo 走 models.dev/logos。
- 插件安装双闸：`isPublicHostname`（拒私网）+ `isHttpsGitUrl`（只收 https）；ZIP 安装同样 https+地址钉死 → HTTP 内网全断。
- 技能源解析只认 `https://` 与 `git@`（`skills-catalog/source.js`），http 直接 invalidSource。
- `contributes.tools` **只是展示**，不能给 agent 注册工具；要加内部工具只能走 MCP。
- 插件有 **6 种挂载位**：rail 图标、全屏 page、statusSection、fileEditors、service.surface 停靠、popover。
- Enterprise 下带 service/network/origins/transcript 的插件只认 `allowedExtensions` 的 Git 仓库；ZIP 恒关；文件夹要 `allowLocalExtensions`。
- `policy.opencodeBinary` 同时关掉 v2 自动安装（canInstall=false）与升级路由（409），是内网规避 `v2-install.js` 硬编码公网的关键。
- 新增 policy 键要改 5 处（schema / parse 解构 / parse 返回 / **invalid 早返回** / 消费点）；`readEnterprisePolicy` 有 14 个直接调用方。
- 隔离空间子系统 `server/lib/spaces`：默认关闭，开启需 Docker + ~1.6GB 镜像。
- 根 package.json 的依赖是**工作区重复声明**，web/ui 各自声明 express/zod/react；抽包发布无需改依赖。
